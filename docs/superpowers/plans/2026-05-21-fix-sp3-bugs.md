## Task 1: Bug #1 — Clock em America/Sao_Paulo (TDD)

`ClockConfig.clock()` retorna `Clock.system(ZoneOffset.UTC)`. Isso faz `OrderService.java:62` (`LocalDateTime.now(clock)`) avaliar o horário em UTC, e a configuração de horários do `application.yml` é em BRT. A partir das 21h BRT a loja "fecha" indevidamente.

`OrderControllerIT.TestClock` injeta um `Clock.fixed(...)` como `@Primary`, então este fix **não quebra os ITs existentes**.

**Files:**
- Create: `backend/src/test/java/com/bragas/api/common/ClockConfigTest.java`
- Modify: `backend/src/main/java/com/bragas/api/common/ClockConfig.java`

```js
import fs from 'node:fs';

const ts = fs.readFileSync(
  "C:/Users/guerr/OneDrive/Desktop/Repositorios/Projetos/Braga's Burger/data/menu.ts",
  'utf8',
);

const arrayBody = ts.match(/export const products[^=]*=\s*\[([\s\S]*?)\n\];/)[1];

// Cada bloco entre { e } no nível do array
const objects = [];
let depth = 0, start = -1;
for (let i = 0; i < arrayBody.length; i++) {
  const c = arrayBody[i];
  if (c === '{') { if (depth === 0) start = i; depth++; }
  else if (c === '}') { depth--; if (depth === 0) objects.push(arrayBody.slice(start, i + 1)); }
}

function field(block, name) {
  // Suporta valores: 'string', "string", true, false, número
  const re = new RegExp(`${name}\\s*:\\s*('([^']*)'|"([^"]*)"|(true|false)|([0-9]+(?:\\.[0-9]+)?))`);
  const m = block.match(re);
  if (!m) return null;
  return m[2] ?? m[3] ?? (m[4] != null ? m[4] === 'true' : Number(m[5]));
}

const products = objects.map((blk) => ({
  id: field(blk, 'id'),
  categoryId: field(blk, 'categoryId'),
  name: field(blk, 'name'),
  price: field(blk, 'price'),
  available: field(blk, 'available'),
}));

// Manter esgotado-test (usado em OrderControllerIT pra testar product-unavailable)
products.push({
  id: 'esgotado-test',
  categoryId: 'burgers',
  name: 'Teste Esgotado',

  available: false,
});

  "C:/Users/guerr/OneDrive/Desktop/Repositorios/Projetos/Braga's Burger/backend/src/main/resources/data/products.json",

);

console.log('products written:', products.length);
console.log('has esgotado-test:', products.some((p) => p.id === 'esgotado-test'));
console.log('has braguinha:', products.some((p) => p.id === 'braguinha'));
```
